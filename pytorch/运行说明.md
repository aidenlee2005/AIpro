# PyTorch 训练与并行运行说明

## 环境要求
- Python + PyTorch + torchvision（支持 CUDA）。
- 至少 1 张 GPU；若需数据并行（DDP），需要 2 张及以上 GPU，使用 `torchrun` 启动。
- 数据会自动下载到 `./data`。

## 单卡训练（`single_gpu.py`）
```bash
cd /root/autodl-tmp/pytorch
python single_gpu.py --epochs 10 --batch-size 128 --lr 0.01 --momentum 0.9 --num-workers 4 \
  --save ./pytorch/cifar_net.pth --logdir pytorch/runs/cifar10_single
```
- 输出：每个 epoch 打印 loss/耗时/吞吐；测试集准确率；权重保存在 `--save` 路径。
- TensorBoard 日志：`--logdir`（默认 `pytorch/runs/cifar10_single`）。
tensorboard --logdir=pytorch/runs/cifar10_single

## 多卡数据并行（DDP，`ddp.py`）
```bash
cd /root/autodl-tmp/pytorch
# 以 2 卡为例，可按需修改 --nproc_per_node
torchrun --nproc_per_node=2 ddp.py --backend gloo --epochs 10 --batch-size 128 --lr 0.01 --momentum 0.9 --num-workers 4 --save ./pytorch/cifar_net_ddp.pth
```
- 每张卡会跑一个进程；日志与评测仅在 rank0 打印并保存权重。
- 吞吐打印为“全局”吞吐（单进程吞吐×GPU 数）。
