- 2025-12-22 VGG 性能优化
    *   **问题排查**:
        *   发现 VGG 模型训练异常缓慢 (~42s/epoch)，远慢于预期。
        *   通过性能分析定位到瓶颈在于 `Conv2d` 层的 Bias 加法操作。原实现使用 Python 端的 `out + self.bias.reshape(...).broadcast_to(...)`，导致了大量的显存拷贝和 Python 调度开销。
    *   **优化方案**:
        *   实现了 `ConvReLU` 融合算子，将 Convolution、Bias Add 和 ReLU 激活融合为一个 CUDA Kernel 调用。
        *   在 `framework/optimizer.py` 中引入 `ConvReLU` 模块，替代标准的 `Conv2d + ReLU` 组合。
    *   **优化结果**:
        *   VGG 训练速度从 **42s/epoch** 提升至 **8.5s/epoch**，速度提升约 **5倍**。

- 2025-12-22 ResNet 性能深度优化
    *   **Global Average Pooling (GAP) 算子实现**:
        *   问题: 原 ResNet 实现中使用 Python 端的 `x.sum(axes=(2, 3)) / (H * W)` 进行全局平均池化，导致巨大的 Python 循环和数据传输开销，ResNet 训练极慢 (~99s/epoch)。
        *   解决: 在 CUDA 后端实现了 `global_avg_pool_forward` 和 `global_avg_pool_backward` 算子，并暴露给 Python 端。
        *   效果: 训练速度提升至 ~78s/epoch。
    *   **Conv2d 算子重构 (cuDNN)**:
        *   问题: 原 `forward_conv2d` 和 `backward_conv2d` 使用手写的 `im2col` + `gemm` 实现，显存占用大且计算效率低。
        *   解决: 使用 `cudnnConvolutionForward` 和 `cudnnConvolutionBackward` 系列 API 替换了手写实现，利用了 NVIDIA 官方的高度优化卷积内核。
    *   **BatchNorm 算子重构 (cuDNN)**:
        *   问题: 原 BatchNorm 实现需要多次启动 CUDA Kernel 分别计算均值、方差和归一化，显存带宽利用率低。
        *   解决: 使用 `cudnnBatchNormalizationForwardTraining` 和 `cudnnBatchNormalizationBackward` 替换了手写实现，单次 Pass 完成计算。
    *   **日志系统修复**:
        *   修复了 `ExperimentLogger` 在不同目录下运行时日志文件路径不一致的问题，强制使用绝对路径。
    *   **最终性能**:
        *   ResNet 训练速度从 **99s/epoch** 提升至 **42.8s/epoch**，速度提升约 **2.3倍**。
        *   相比 PyTorch (~15s/epoch)，性能差距从 6.6倍 缩小至 2.8倍。
